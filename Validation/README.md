# 验证记录

日期：2026-09-21；平台：本机 Apple Silicon macOS；内核：REBOUND 4.4.11 IAS15。

## 已完成的基准

- `four-body-10000-v1.1.json`：层级四体完成 10,000 标准年，36.78 秒，最大归一化能量误差 3.87e-16，10,000 个完整恒纪元年。
- `kepler-10000.json`：圆轨道与 e=0.6 二体解析基准各 10,000 周期；文件中保留位置与守恒量误差。
- `escape-1600056934119823229.json`、`escape-7842035361616645170.json`：原用户混沌初值分别在约 196.57、379.00 标准年确认为远场逃逸后停止，没有继续生成未来年份。
- 测试日志：项目 `.build/verification-1.2-final.log`。覆盖检查点一致性、事件细化与精度收敛、碰撞、逃逸、旧存档、连续轨迹及显示半径回归。

耗时依赖设备、轨道和精度设置。复杂近遇的耗时可以显著高于层级基准。数值误差监控与收敛测试不能消除混沌系统对初值和舍入误差的长期敏感性。

## 本轮应用修复

- 原崩溃栈指向轨迹数组嵌套读写引发的 Swift 独占访问冲突。轨迹改为独立、有容量上限的历史缓冲；测试持续跨越原容量限制。
- 1 与 10 年/秒使用相同的 1/120 年最大显示采样间隔，物理积分独立于屏幕帧率。
- 加载与存档处理位于后台；界面计算更新限频，表格只展示当前页的最多 200 条。全部数据仍参与积分、统计与导出。
- Metal 尺寸变化合并处理，复用场景几何且不阻塞等待积压帧。
- 星体增强显示尺寸在取景时固定；前景行星不会改变恒星尺寸；真实物理半径不受影响。

## 三星穿行筛选：已停止

按用户明确要求，轨道筛选和候选长时间核验均已停止，不会自动恢复。
`Candidates`、`WideCandidates` 内 `screen-*.json` 只是快速预筛记录，不能作为万年宜居证明。
完整核验报告以 `calendar-*.json` 命名；现有已完成记录中没有同时满足三星近访与超过 500 个宜居标准年的样例。
尚未完成的运行不计为通过。未达标候选不加入应用菜单。

统计门槛使用宜居区间的实际累计时长除以 10,000，不使用已经计算的年份数作分母。
近访记录来自已接受的气候采样：行星的最近恒星在两个参考距离内，记录首次近访时刻。
该条件表示穿行/接近，不等同于已证明绕该星长期束缚。快速预筛与气候细算的积分目标不同，混沌初值可能分叉，二者不能混用作为同一条确定轨迹的证据。
